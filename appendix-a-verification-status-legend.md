# Appendix A: Verification Status Legend

Every substantive claim in this book carries one of the following labels. This appendix defines them once so individual chapters can use them without re-explaining each time.

| Label | Meaning |
|---|---|
| **Confirmed** | Stated directly by FreClean in its own published materials, or verifiable from a cited third-party source. Treated as fact for the purposes of this book. |
| **Planned** | Part of FreClean's stated strategy or intention, but not yet operating or in effect. |
| **TBD** | To Be Determined, expected to exist eventually, but not yet provided or decided. |
| **Not Yet Verified** | A claim (certification, regulatory approval, partnership, financial figure) that would normally require third-party verification and has not been verified. Neither confirmed nor denied, genuinely unknown. |
| **Not Publicly Disclosed** | FreClean may have this information internally, but it has not been made public and this book has no access to it. |
| **Concept** | A proposed idea, framework, or visual that has not been implemented or produced, used especially for illustrative product visuals and financial scenarios. |
| **Illustrative Scenario** | A numerical example built on stated assumptions, used to demonstrate a financial or operational framework, not a forecast, projection, or claim about FreClean's actual future performance. |
| **Assumption** | A premise this book adopts for the sake of analysis, stated explicitly so the reader can agree, disagree, or ask for it to be revisited. |

## How this book applies these labels

- A claim with no label attached should be read as **Confirmed** only if it is a plain factual restatement of FreClean's own published mission, values, product names, or similar static material.
- Any number that looks like a forecast, projection, or financial figure and is not explicitly labeled **Confirmed** with a cited source should be read as **Illustrative Scenario** or **Assumption**, never as real FreClean performance data.
- This book does not use unlabeled adjectives ("leading," "proven," "trusted") to imply verification that has not occurred.
